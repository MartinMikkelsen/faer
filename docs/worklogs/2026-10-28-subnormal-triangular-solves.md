# Triangular solves with subnormal pivots (#74)

## Decisions

- Correct the shared non-unit base case, which is reached by lower solves, reversed upper solves, both conjugations and larger recursive systems. A leaf containing a nonzero pivot whose largest component magnitude is subnormal uses residual-first substitution. This avoids both an overflowing reciprocal and pre-normalized off-diagonal coefficients that would produce Inf/NaN before cancellation.
- Divide real residuals directly. For complex pivots with a finite reciprocal, retain multiplication by that reciprocal, including normal or huge pivots sharing a leaf with a tiny pivot. Plain complex division would square a huge divisor or underflow the square of a tiny one.
- When a complex reciprocal is non-finite, multiply numerator and divisor by `1 / (4 * MIN_POSITIVE)` before dividing. This is an exact power-of-two scale for native f32/f64: the smallest nonzero scaled components are 2^-25 / 2^-54, whose squares are normal, while scaled subnormal components remain below 1/4. The latter leaves headroom in the numerator and both complex products for a representable quotient.
- Fold the previous real-singleton exception into this shared fallback. The existing unrolled arithmetic remains for leaves without a subnormal pivot; the unit-diagonal base kernel is byte-identical to main. The check scans at most four diagonal entries, introduces no heap allocation or scratch requirement, and keeps the existing scheduling and API. Its runtime overhead remains unmeasured.
- Ordinary tests use exact, independently known all-one solutions. They cover native f32/f64/c32/c64, positive/negative real pivots, real/imaginary/mixed complex pivots, both triangle directions and conjugations, two RHS columns in column-major and transposed row-major views, and thirteen dimensions from 1 to 129 around leaf/recursion boundaries. Normal and MIN_POSITIVE/2 controls retain the earlier reciprocal improvement. Coupled bidiagonal cases alternate tiny and huge pivots; their zero interior RHS requires forming the residual before division and avoids silently weakening the test to finiteness.
- The shared call path reaches LU, QR, Cholesky, triangular inversion, Hessenberg and Householder updates. Acceptance before merge must include campaign families reaching those callers, including decomposition consumers of Householder updates, and collateral controls under the adoption protocol. This is a correctness candidate, with no performance claim or general LATRS-style overflow-scaling contract.

- Fresh main baseline: `2592bad8cef0bbba00d1ae31c0442ea6cf3c5310`, Rust 1.96.0 on aarch64-apple-darwin. The separate #73 checkout was preserved; its SVD changes are not included here. All three new regressions fail before the correction with Inf/NaN instead of the literal expected value one.
- The final ordinary regression grid completes 3,744 sequential public solve calls with the exact expected result. The complete triangular test selection, including ignored LAPACK groups and the existing singleton regressions, passes all 33 tests. Its 11,472 configured LAPACK calls are all attempted, with zero call failures or numerical diagnostics; 144 of those calls exercise the suite's sequential/2T/4T parallel-path group.
- The final ordinary workspace run reports 462 faer passes and 138 ignored tests. The same three failures occur on the baseline: `linalg::matmul::internal::tests::empty_strict_triangle_preserves_parent_guards`, `linalg::matmul::internal::tests::strict_triangle_maps_preserve_stored_entries_and_parent_guards`, and `linalg::matmul::internal::tests::strict_triangle_preserves_nonempty_parent_guards`. No unrelated test or tolerance was changed.
- All 25 public integration tests, 60 documentation tests and the std-only build pass. The changed source passes rustfmt and the diff whitespace check. Detailed reproduction commands, baseline/final logs and the source diff are in the [evidence archive](evidence/2026-10-28-subnormal-triangular-solves.tar.gz).
- No upstream checkout was measured and no upstream feedback is part of this work. Other platforms, the full opt-in non-triangular LAPACK suite and benchmark acceptance remain unverified.
- Leaves without a subnormal pivot keep the pre-normalized coefficients `-l_ij / l_jj`, which can overflow for a normal tiny pivot beside a large off-diagonal entry. With f64 pivot 2^-1000 and off-diagonal 2^30 in the same leaf, an exact unit-vector solution returns NaN, while the same pair split across leaves is solved exactly by the residual-forming block update. This is unchanged from the baseline and outside the subnormal scope here; always forming residuals in non-unit leaves would remove it but needs benchmark acceptance.
